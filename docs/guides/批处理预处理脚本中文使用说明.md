# EEGLAB 预处理辅助脚本中文使用说明

## 1. 脚本用途

这套脚本用于在 `MATLAB + EEGLAB` 环境中，自动完成 EEG 预处理的前六步，并将结果保存为 `.set/.fdt` 文件。

当前自动完成的固定步骤为：

1. 导入 `.cnt` 文件
2. 加载电极定位 `.ced` 文件
3. 删除 `HEO / VEO / EKG / EMG`
4. 降采样
5. 高通、低通、固定 `49-51 Hz` 工频陷波
6. 固定使用 `M1 / M2` 重参考

第 7 步及之后的处理仍由你手动完成。

默认电极定位文件路径为：

- `F:\CJZFile\EEG_M1\standard_1005.ced`

现在 GUI 中可以自行选择或手动填写其他 `.ced` 文件。

## 2. 主要文件

- [launch_preprocess_gui.m](/F:/CJZProjectFile/EEGPreProcessScript/launch_preprocess_gui.m)：图形界面入口
- [run_preprocess_batch.m](/F:/CJZProjectFile/EEGPreProcessScript/run_preprocess_batch.m)：命令行批处理入口

- [run_preprocess_from_gui.m](/F:/CJZProjectFile/EEGPreProcessScript/src/run_preprocess_from_gui.m)：GUI 调用桥接
- [validate_lookup_file_path.m](/F:/CJZProjectFile/EEGPreProcessScript/src/validate_lookup_file_path.m)：电极定位文件校验
- [preprocess_config.json](/F:/CJZProjectFile/EEGPreProcessScript/config/preprocess_config.json)：保存参数配置

## 3. 可修改参数

可修改并保存的参数包括：

- `target_sample_rate`
- `highpass_hz`
- `lowpass_hz`
- `overwrite_existing`
- `save_log`
- `eeglab_path`
- `lookup_file`

其中：

- `lookup_file` 默认值为 `F:\CJZFile\EEG_M1\standard_1005.ced`
- GUI 中可以手动输入或选择 `.ced`
- 运行前会校验是否为空、是否存在、是否为 `.ced`

固定不改的部分包括：

- `49-51 Hz` 陷波始终执行
- `M1/M2` 重参考始终执行
- `HEO/VEO/EKG/EMG` 始终删除

## 4. GUI 启动方式

先在 MATLAB 中进入脚本目录，并加入路径：

```matlab
cd('F:\CJZProjectFile\EEGPreProcessScript');
addpath(genpath('F:\CJZProjectFile\EEGPreProcessScript'));
```

然后启动 GUI：

```matlab
launch_preprocess_gui
```

## 5. GUI 的使用流程

GUI 只有一种输入模式：手动选择任意目录。

使用步骤：

1. 点击 `Select Source`，选择任意源目录
2. 点击 `Select Output`，选择输出根目录
3. 在 `Lookup File` 一栏中：
   - 可以直接手动输入 `.ced` 路径
   - 也可以点击 `Select File` 选择 `.ced`
4. 查看界面上的 `CNT files` 预览数量
5. 按需修改采样率、高通、低通
6. 先点击 `Smoke Test` 做 1 个文件的烟雾测试
7. 确认没问题后，再点击 `Start Processing`

## 6. Lookup File 的规则

GUI 中的 `Lookup File` 有以下规则：

- 默认值仍然是 `F:\CJZFile\EEG_M1\standard_1005.ced`
- 可以手动修改
- 可以通过 `Select File` 选择 `.ced`
- 不能为空
- 文件必须真实存在
- 扩展名必须是 `.ced`
- `Load Config` / `Save Config` 会一起读写这个值

如果路径不合法，GUI 会在真正开始批处理前直接报错，不会继续进入预处理流程。

## 7. GUI 的路径规则

GUI 会递归处理“所选目录”下面的所有 `.cnt` 文件。

输出时保留“所选目录以下”的层级结构，并以“所选目录名”作为输出中的顶层目录。

例如：

- 选择的源目录：
  `F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG\基线\sub05殷文海`
- 选择的输出根目录：
  `F:\CJZFile\EEG_scriptProcess_GUI`
- 输出结果：
  `F:\CJZFile\EEG_scriptProcess_GUI\sub05殷文海\...`

如果你选择的是整个患者目录：

- 源目录：
  `F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG`
- 输出结果：
  `F:\CJZFile\EEG_scriptProcess_GUI\Patient_tACS_M1_EEG\...`

## 8. GUI 烟雾测试建议

第一次使用建议先做烟雾测试：

1. 选择源目录
2. 选择输出目录
3. 确认 `Lookup File` 指向正确的 `.ced`
4. 点击 `Smoke Test`
5. 确认界面统计结果中：
   - `Processed: 1`
   - `Failed: 0`
6. 去输出目录确认已经生成一对 `.set/.fdt`
7. 用 EEGLAB 打开 `.set` 手动检查处理结果

## 9. 命令行使用方式

查看当前配置：

```matlab
cfg = load_preprocess_config();
disp(cfg)
```

修改并保存参数：

```matlab
cfg = load_preprocess_config();
cfg.target_sample_rate = 250;
cfg.highpass_hz = 0.5;
cfg.lowpass_hz = 45;
save_preprocess_config(cfg);
```

处理患者目录：

```matlab
results = run_preprocess_batch("F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG");
```

处理健康人目录：

```matlab
results = run_preprocess_batch("F:\CJZFile\EEG_M1\Health-tACS-M1-RestingStateEEG");
```

执行一键烟雾测试：

```matlab
report = smoke_test_preprocess();
```

健康人目录烟雾测试：

```matlab
report = smoke_test_preprocess("F:\CJZFile\EEG_M1\Health-tACS-M1-RestingStateEEG");
```

临时覆盖参数但不保存配置：

```matlab
results = run_preprocess_batch( ...
    "F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG", ...
    'target_sample_rate', 250, ...
    'highpass_hz', 0.5, ...
    'lowpass_hz', 45, ...
    'output_root', "F:\CJZFile\EEG_scriptProcess_Test");
```

## 12. 建议你手动检查的内容

烟雾测试或正式运行后，建议检查：

- `.set/.fdt` 是否真实生成
- 采样率是否等于设置值
- 选择的 `.ced` 是否正确
- `HEO/VEO/EKG/EMG` 是否已删除

- `M1/M2` 重参考是否生效
- 输出目录层级是否符合所选源目录

## 13. 常见问题

### 13.1 MATLAB 找不到 EEGLAB

可能原因：

- EEGLAB 没有加入 MATLAB 路径
- `eeglab_path` 没设置

处理方法：

- 先手动启动 EEGLAB
- 或在配置中填写 `eeglab_path`
- 或手动 `addpath(genpath(EEGLAB目录))`

### 13.2 电极定位文件无效

可能原因：

- 路径为空
- 文件不存在
- 选择的不是 `.ced`

处理方法：

- 在 GUI 的 `Lookup File` 中重新选择 `.ced`
- 确认文件真实存在
- 确认扩展名为 `.ced`

### 13.3 找不到 M1 或 M2

可能原因：

- 原始数据中通道标签异常
- 电极定位或通道信息不一致

处理方法：

- 检查数据中的通道标签
- 检查当前使用的 `.ced`
- 确认 `M1` / `M2` 未被误删

### 13.4 输出文件已存在但没有覆盖

原因：

- `overwrite_existing = false`

处理方法：

- 在 GUI 勾选 `Overwrite`
- 或在配置文件里把 `overwrite_existing` 改为 `true`

### 13.5 只处理了少量文件

原因：

- `limit_files` 不为 `0`
- 你运行的是烟雾测试

处理方法：

- 用完整批处理入口
- 确认 `limit_files = 0`
