# EEGLAB 预处理辅助脚本中文使用说明

## 1. 脚本用途

这套脚本用于在 `MATLAB + EEGLAB` 环境中，自动完成 EEG 预处理的前六步，并将结果保存为 `.set/.fdt` 文件。

当前自动完成的固定步骤为：

1. 导入 `.cnt` 文件
2. 加载电极定位文件 `F:\CJZFile\EEG_M1\standard_1005.ced`
3. 删除 `HEO / VEO / EKG / EMG`
4. 降采样
5. 高通、低通、固定 `49-51 Hz` 工频陷波
6. 固定使用 `M1 / M2` 重参考

第 7 步及之后的处理仍由你手动完成。

## 2. 主要文件

- [launch_preprocess_gui.m](/F:/CJZProjectFile/EEGPreProcessScript/launch_preprocess_gui.m)：图形界面入口
- [run_preprocess_batch.m](/F:/CJZProjectFile/EEGPreProcessScript/run_preprocess_batch.m)：命令行批处理入口
- [smoke_test_preprocess.m](/F:/CJZProjectFile/EEGPreProcessScript/smoke_test_preprocess.m)：一键烟雾测试
- [load_preprocess_config.m](/F:/CJZProjectFile/EEGPreProcessScript/load_preprocess_config.m)：配置加载入口
- [save_preprocess_config.m](/F:/CJZProjectFile/EEGPreProcessScript/save_preprocess_config.m)：配置保存入口
- [run_preprocess_from_gui.m](/F:/CJZProjectFile/EEGPreProcessScript/src/run_preprocess_from_gui.m)：GUI 调用桥接
- [preprocess_config.json](/F:/CJZProjectFile/EEGPreProcessScript/config/preprocess_config.json)：保存参数配置

## 3. 可修改参数

可修改并保存的参数包括：

- `target_sample_rate`
- `highpass_hz`
- `lowpass_hz`
- `overwrite_existing`
- `save_log`
- `eeglab_path`

固定不改的部分包括：

- `49-51 Hz` 陷波始终执行
- `M1/M2` 重参考始终执行
- `HEO/VEO/EKG/EMG` 始终删除

## 4. GUI 启动方式

先在 MATLAB 中进入脚本目录，并加入路径：

```matlab
cd('F:\CJZProjectFile\EEGPreProcessScript');
addpath(genpath('F:\CJZProjectFile\EEGPreProcessScript'));
```

然后启动 GUI：

```matlab
launch_preprocess_gui
```

## 5. GUI 的使用流程

GUI 只有一种输入模式：手动选择任意目录。

使用步骤：

1. 点击 `Select Source`，选择任意源目录
2. 点击 `Select Output`，选择输出根目录
3. 查看界面上的 `CNT files` 预览数量
4. 按需修改采样率、高通、低通
5. 先点击 `Smoke Test` 做 1 个文件的烟雾测试
6. 确认没问题后，再点击 `Start Processing`

## 6. GUI 的路径规则

GUI 会递归处理“所选目录”下面的所有 `.cnt` 文件。

输出时保留“所选目录以下”的层级结构，并以“所选目录名”作为输出中的顶层目录。

例如：

- 选择的源目录：
  `F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG\基线\sub05殷文海`
- 选择的输出根目录：
  `F:\CJZFile\EEG_scriptProcess_GUI`
- 输出结果：
  `F:\CJZFile\EEG_scriptProcess_GUI\sub05殷文海\...`

如果你选择的是整个患者目录：

- 源目录：
  `F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG`
- 输出结果：
  `F:\CJZFile\EEG_scriptProcess_GUI\Patient_tACS_M1_EEG\...`

## 7. GUI 烟雾测试建议

第一次使用建议先做烟雾测试：

1. 选择源目录
2. 选择输出目录
3. 点击 `Smoke Test`
4. 确认界面统计结果中：
   - `Processed: 1`
   - `Failed: 0`
5. 去输出目录确认已经生成一对 `.set/.fdt`
6. 用 EEGLAB 打开 `.set` 手动检查处理结果

## 8. 命令行使用方式

查看当前配置：

```matlab
cfg = load_preprocess_config();
disp(cfg)
```

修改并保存参数：

```matlab
cfg = load_preprocess_config();
cfg.target_sample_rate = 250;
cfg.highpass_hz = 0.5;
cfg.lowpass_hz = 45;
save_preprocess_config(cfg);
```

处理患者目录：

```matlab
results = run_preprocess_batch("F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG");
```

处理健康人目录：

```matlab
results = run_preprocess_batch("F:\CJZFile\EEG_M1\Health-tACS-M1-RestingStateEEG");
```

执行一键烟雾测试：

```matlab
report = smoke_test_preprocess();
```

健康人目录烟雾测试：

```matlab
report = smoke_test_preprocess("F:\CJZFile\EEG_M1\Health-tACS-M1-RestingStateEEG");
```

临时覆盖参数但不保存配置：

```matlab
results = run_preprocess_batch( ...
    "F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG", ...
    'target_sample_rate', 250, ...
    'highpass_hz', 0.5, ...
    'lowpass_hz', 45, ...
    'output_root', "F:\CJZFile\EEG_scriptProcess_Test");
```

## 10. 输出规则

输出文件格式固定为：

- `.set`
- `.fdt`

默认配置下，输出根目录为：

- `F:\CJZFile\EEG_scriptProcess`

日志目录为：

- `F:\CJZFile\EEG_scriptProcess\logs\`

如果使用 GUI，则输出根目录以你在界面中选择的目录为准。

## 11. 建议你手动检查的内容

烟雾测试或正式运行后，建议检查：

- `.set/.fdt` 是否真实生成
- 采样率是否等于设置值
- `HEO/VEO/EKG/EMG` 是否已删除
- `49-51 Hz` 陷波是否生效
- `M1/M2` 重参考是否生效
- 输出目录层级是否符合所选源目录
