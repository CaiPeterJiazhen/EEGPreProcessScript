# EEG 预处理 GUI 设计

**目标**

为现有的 EEGLAB 批处理预处理脚本增加一个基于 `uifigure` 的图形界面，支持用户手动选择任意源目录、任意输出目录，并递归处理所选目录下所有 `.cnt` 文件。GUI 仍复用现有预处理核心逻辑，不重写 EEGLAB 处理流程。

**设计原则**

- GUI 只负责交互和状态显示，不负责 EEG 处理细节
- 命令行入口和 GUI 入口共用同一套批处理核心
- 输出目录结构只保留“所选目录以下”的层级结构
- GUI 支持完整处理和烟雾测试两种运行方式
- 现有固定处理规则不暴露为可编辑参数

---

## 1. 已确认功能范围

GUI 需要支持以下功能：

- 手动选择任意源目录
- 手动选择任意输出目录
- 自动递归统计所选源目录下的 `.cnt` 文件数
- 编辑参数：
  - 目标采样率
  - 高通频率
  - 低通频率
  - 是否覆盖已有结果
  - 是否保存日志
- 从 `preprocess_config.json` 加载当前配置
- 将 GUI 当前配置保存回 `preprocess_config.json`
- 执行完整批处理
- 执行烟雾测试（仅处理 1 个文件）
- 实时显示处理日志
- 显示处理统计结果

固定规则保持不变：

- 删除 `HEO`、`VEO`、`EKG`、`EMG`
- 固定执行 `49-51 Hz` 的 50 Hz 陷波
- 固定使用 `M1/M2` 重参考

---

## 2. 输入与输出规则

### 2.1 输入模式

GUI 只有一种输入模式：

- 用户手动选择任意目录

该目录可以是：

- 患者总目录
- 健康人总目录
- 某一阶段目录
- 某个单独患者/受试者目录

只要该目录下递归存在 `.cnt` 文件，GUI 就应允许处理。

### 2.2 输出规则

用户手动选择输出根目录。

输出目录结构只保留“所选目录以下”的层级结构。

例子：

- 选择源目录：`F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG\基线\sub05殷文海`
- 选择输出目录：`F:\out`

则输出为：

- `F:\out\sub05殷文海\*.set`
- `F:\out\sub05殷文海\*.fdt`

如果选择的是更大的目录，例如：

- 源目录：`F:\CJZFile\EEG_M1\Patient_tACS_M1_EEG`

则输出为：

- `F:\out\Patient_tACS_M1_EEG\...`

这意味着现有路径映射逻辑可继续复用，因为它本质上已经按“所选源目录的相对路径”输出。

## 3. GUI 布局

GUI 使用单窗口 `uifigure`，分为四个区域。

### 3.1 路径区域

包含：

- 源目录文本框
- `选择源目录` 按钮
- 输出目录文本框
- `选择输出目录` 按钮
- `CNT 文件数` 预览标签

行为：

- 用户选择源目录后，立即递归扫描 `.cnt`
- 将文件数回填到界面
- 若文件数为 0，阻止执行处理

### 3.2 参数区域

包含：

- 采样率数值框
- 高通数值框
- 低通数值框
- `覆盖已有结果` 复选框
- `保存日志` 复选框

不包含固定规则参数，避免误操作。

### 3.3 状态与日志区域

包含：

- 当前状态标签
- 统计结果标签
- 最后日志文件路径文本框
- 多行日志文本区

日志文本区需要支持动态追加，显示：

- 目录检查信息
- 当前处理进度
- 单文件完成信息
- 单文件失败信息
- 总结信息

### 3.4 操作按钮区域

包含：

- `加载配置`
- `保存配置`
- `开始处理`
- `烟雾测试`
- `清空日志`

## 4. 后端结构

为了保持职责清晰，建议新增 GUI 相关文件，并扩展现有批处理入口。

### 4.1 保留的现有核心

- `preprocess_cnt_file.m`
- `collect_cnt_files.m`
- `find_reference_channel_indices.m`
- `normalize_preprocess_config.m`
- `load_preprocess_config.m`
- `save_preprocess_config.m`

### 4.2 需要扩展的现有入口

`run_preprocess_batch.m` 需要增加：

- 自定义输出根目录支持
- 可选日志回调 `log_callback`

GUI 将通过日志回调实时刷新日志区，而不只依赖 `fprintf`

### 4.3 需要新增的文件

- `launch_preprocess_gui.m`
  - 创建 GUI
  - 绑定控件与回调
- `run_preprocess_from_gui.m`
  - 将 GUI 输入整理为运行参数
  - 调用 `run_preprocess_batch`
- `count_cnt_files.m`
  - 单独负责目录扫描计数，便于 GUI 更新预览
- `append_gui_log.m`
  - 统一写日志到 GUI 文本区
- `collect_gui_config.m`
  - 从界面控件读取配置
- `apply_config_to_gui.m`
  - 将配置回填到界面控件

## 5. 运行时行为

### 5.1 输入校验

运行前需要检查：

- 是否已选择源目录
- 是否已选择输出目录
- 源目录是否存在
- 输出目录是否存在或可创建
- 源目录下是否存在 `.cnt`
- 参数是否合法：
  - 采样率 > 0
  - 高通 > 0
  - 低通 > 0
  - 高通 < 低通

输入错误使用弹框提示，并阻止运行。

### 5.2 批处理期间控件策略

运行中应禁用：

- 目录选择按钮
- 参数输入控件
- 保存配置按钮
- 开始处理按钮
- 烟雾测试按钮

运行结束后恢复。

第一版不实现中途取消，避免把 EEGLAB 处理状态做复杂。

### 5.3 烟雾测试模式

烟雾测试与完整处理共用同一后端，仅在本次运行中临时设置：

- `limit_files = 1`
- 不改变正式配置文件中的长期参数

---

## 6. 错误处理策略

### 6.1 输入前错误

直接弹框，不进入处理流程：

- 未选目录
- 参数非法
- 源目录无 `.cnt`

### 6.2 环境错误

直接终止本次运行：

- 找不到 EEGLAB
- 找不到 `standard_1005.ced`

### 6.3 单文件错误

单个文件失败时：

- 记录到 GUI 日志区
- 记录到 CSV 日志
- 状态记为 `failed`
- 继续处理后续文件

---

## 7. 验证方案

GUI 实现后按以下顺序验证：

1. GUI 启动验证
   - 窗口能打开
   - 控件初始值正确
2. 配置验证
   - 能加载配置
   - 能保存配置
3. 源目录扫描验证
   - 不同层级目录都能统计到正确的 `.cnt` 数量
4. GUI 烟雾测试
   - 单文件能生成 `.set/.fdt`
   - 日志区和统计区正常
5. 单患者目录验证
   - 输出结构只保留所选目录以下层级
6. 整目录验证
   - 患者整目录
   - 健康人整目录

---

## 8. 第一版不实现的内容

为了收敛范围，第一版明确不做：

- 中途取消任务
- 内置频谱图预览
- 自动打开输出目录
- 图表式统计面板
- 多任务并行处理

这些都属于后续增强项，不影响当前核心需求。

---

## 9. 风险与注意事项

- 当前环境里无法通过命令行 MATLAB 做自动验证，原因是本机许可证错误，而不是脚本设计本身问题
- GUI 依赖 `uifigure`，要求 MATLAB 具备相应图形能力
- GUI 日志区应以文本追加为主，不依赖复杂组件
- 后端改造必须保持命令行脚本兼容，不能破坏现有 `run_preprocess_batch.m` 与 `smoke_test_preprocess.m`
